# Security

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's Report a vulnerability form](https://github.com/eeeggg/your-turn/security/advisories/new).
Do not disclose vulnerabilities in public issues or pull requests.

Include, where possible:

- The Your Turn version or source commit, VS Code version, and operating system.
- A description of the issue and its potential impact.
- Minimal reproduction steps and any relevant configuration.
- A small, sanitized example or proof of concept using data you are authorized
  to share.

Agent transcripts, ACP traffic exports, screenshots, and logs can contain
credentials, source code, prompts, file contents, and private paths. Remove
sensitive material before sharing it, even in a private report. Never include
live credentials; revoke or rotate any that have been exposed.

The maintainers will use the private report to discuss reproduction, impact,
and coordinated disclosure. Please allow time for investigation before
publishing details. No fixed response or resolution time is promised.

For ordinary bugs and feature requests, use
[GitHub Issues](https://github.com/eeeggg/your-turn/issues).
